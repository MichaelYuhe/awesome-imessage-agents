# Awesome iMessage Agents

> A curated list of AI agents you can use from Apple's Messages app—no separate app required.

This list focuses on consumer-facing agents with a live official website and current official documentation for iMessage, Apple Messages, or SMS access. Every entry below was reviewed on **August 20, 2026**.

> [!NOTE]
> `iMessage` means the product explicitly documents iMessage access. `SMS` agents still work inside Apple's Messages app, but messages may use your carrier. Availability, pricing, phone numbers, and regional support can change.

## Selection Criteria

An agent belongs in the main list only when all of the following are true:

- It is an end-user product, not messaging infrastructure or a developer gateway.
- Its official website is live.
- Current official material documents access through iMessage, Apple Messages, or SMS.
- A user can access it publicly or follow a clear official onboarding flow.
- Its name, description, transport, and entry link can be verified from official sources.

Agents stay out of the main list when they are shut down, waitlist-only, app-only, infrastructure-only, or missing a verifiable messaging entry. A live domain by itself is not enough.

The current review covered **104 candidates**: **38** are listed here, **46** need more verification, and **20** were excluded. **21 direct phone numbers** in this list were confirmed on official pages; third-party-only numbers were intentionally removed.
